Equipment Service

CreateEquipmentDTO : ( equipmentName , hasSerialNumber , equipmentQuantity , minEquipmentQuantity? , equipmentShelfId? ) to create a new equipment
SearchEquipmentDTO : ( equipmentName? , hasSerialNumber? , equipmentQuantity? , minEquipmentQuantity? , equipmentShelfId? ) to search for existed equipment
UpdateEquipmentDTO : ( equipmentName? , hasSerialNumber? , equipmentQuantity? , minEquipmentQuantity? , equipmentShelfId? ) to update an existed equipment

POST   /equipment               
       createEquipment()      first validate input of creating new equipment from CreateEquipmentDTO  then check if the equipment 
                              doesn't already exist using equipmentExists()  then create new tuple of relation equipment and insert it

GET    /equipment
       getAllEquipments()     find all tuples of equipment schema using  pagination method with 10 limit of a page



GET    /equipment/search
       searchEquipments()      first validate inputs of searching equipment from SearchEquipmentDTO then we return all equipments that matches the 
                              searching options  using  pagination method with 10 limit of a page



GET    /equipment/:id
       getEquipmentById()      first validate equipment id input then check if the equipment id already existed then we will return the all tuple of
                               equipment


PATCH  /equipment/:id
       updateEquipment()       first validate inputs of update equipment from UpdateEquipmentDTO then we check if equipment already existed then we change
                               updated columns
               
       
DELETE /equipment/:id
       deleteEquipment()       first search about equipment using getEquipmentById() then delete it


GET    /equipment/:equipmentId/serialNumbers
       getSerialNumbersByEquipmentId() first validate equipment id input then check if the equipment exists using equipmentExists() 
                                       then return all serial number tuples that belong to this equipment


GET    /equipment/:id/shelves
       getEquipmentShelves()     search about equipment with selecting shelves then return equipment id and name and quantity with listing shelf id and 
                                 name and quantity for each shelf



GET    /equipment/shelves        
       getAllEquipmentsWithShelves()    listing all equipment with their shelves

Serial Number Service 

CreateSerialNumberDTO : ( serialNumberCode, equipmentId, serialNumberStatus? ) to create a new serial number for serialized equipment
UpdateSerialNumberDTO : ( serialNumberCode?, equipmentId?, serialNumberStatus? ) to update an existing serial number 
UpdateSerialNumberStatusDTO : ( serialNumberStatus ) to update only the status of an existing serial number


POST    /serial-number 
        createSerialNumber()      first validate inputs of creating a new serial number from CreateSerialNumberDTO then check if the equipment exists
                                  using equipmentExists() then check if this equipment hasSerialNumber = true then check if the serial number doesn't 
                                  already exist using serialNumberExists() then create and insert the new serial number tuple


GET    /serial-number
       getAllSerialNumbers()     find and return all tuples of SerialNumber schema


GET    /serial-number/:id 
       getSerialNumberById()     first validate serial number id input then check if the serial number already exists then return the complete
                                 serial number tuple


GET    /serial-number/code/:code 
       getSerialNumberByCode()      first validate serial number code input then check if the serial number exists using serialNumberExists() then 
                                    return the complete serial number tuple


GET    /serial-number/status/:status 
       getSerialNumbersByStatus()   first validate serial number status input then return all serial number tuples that have the specified 
                                    status


PATCH  /serial-number/:id 
       updateSerialNumber()      first validate serial number id then validate update inputs from UpdateSerialNumberDTO then check if 
                                 the serial number exists if serialNumberCode is changed: check that the new code is not already used by 
                                 another serial number if equipmentId is changed: check if the new equipment exists check if the new equipment
                                 hasSerialNumber = true then update only the provided columns


PATCH  /serial-number/:id/status
       updateSerialNumberStatus()  first validate serial number id then validate serialNumberStatus from UpdateSerialNumberStatusDTO then check
                                   if the serial number exists then update only serialNumberStatus


DELETE  /serial-number/:id
        deleteSerialNumber()      first search for the serial number using getSerialNumberById() then delete it

         
PATCH    /serial-number/:id/shelf
        insertSerialNumberToShelf()      first CHECK IF serial number equipment and shelf exist then update from srerial number equipment tuple
                                         and update the foreign key of the shelf 




serialNumberExists()

Shelf Service

CreateShelfDTO : ( shelfName, shelfCode ) to create a new shelf
SearchShelfDTO : ( shelfName?, shelfCode? ) to search for existing shelves
UpdateShelfDTO : ( shelfName?, shelfCode? ) to update an existing shelf


POST   /shelf
       createShelf()  first validate inputs of creating a new shelf from CreateShelfDTO then check if the shelf doesn't already exist using shelfExists()
                      then create and insert the new shelf tuple


GET    /shelf
       getAllShelves()    find and return all tuples of Shelf schema


GET    /shelf/search
       searchShelves()    first validate inputs of searching shelves from SearchShelfDTO then return all shelves that match the searching options


GET    /shelf/name/:name
       getShelfByName()   first validate shelf name input then check if the shelf exists then return the complete shelf tuple



GET    /shelf/:id
       getShelfById()     first validate shelf id input then check if the shelf id already exists then return the complete shelf tuple


PATCH  /shelf/:id
       updateShelf()      first validate shelf id then validate update inputs from UpdateShelfDTO then check if the shelf already exists
                          if shelfCode is changed: check that the new shelf code is not already used by another shelf
                          if shelfName is changed:
                             check if your system requires shelf names to be unique
                          if locationId is changed:
                             check if the new location exists
                          then update only the provided columns



DELETE /shelf/:id
       deleteShelf()      first search for the shelf using getShelfById() then check if the shelf contains equipment if equipment exists on this shelf:
                          do not delete the shelf until the equipment is moved or removed otherwise delete the shelf


shelfExists()

Equipment Movement Service

CreateEquipmentMovementDTO : ( equipmentId , serialNumberId? , sourceShelfId? , destinationShelfId? , movementQuantity , movementType ) to create a new equipment movement
SearchEquipmentMovementDTO : ( equipmentId?, serialNumberId?, sourceShelfId?, destinationShelfId?, movementQuantity?, movementType? ) search for equipment movements



POST   /equipment-movement
       createEquipmentMovement()   first validate inputs of creating a new equipment movement from CreateEquipmentMovementDTO then check if the equipment exists
                                   using equipmentExists()
                                   if serialNumberId is provided: check if the serial number exists using serialNumberExists() check if the serial number 
                                   belongs to the specified equipment
                                   if sourceShelfId is provided:  check if the source shelf exists using shelfExists()
                                   if destinationShelfId is provided:
                                   check if the destination shelf exists using shelfExists() then validate the movement using validateMovement then create
                                   and insert the new equipment movement tuple


GET    /equipment-movement
       getAllEquipmentMovements()   find and return all tuples of EquipmentMovement schema


GET    /equipment-movement/search
       searchEquipmentMovements()   first validate searching inputs from SearchEquipmentMovementDTO then return all equipment movement tuples that match the searching
                                    options


GET    /equipment-movement/:id
       getEquipmentMovementById()   first validate movement id input then check if the equipment movement exists using equipmentMovementExists() then return the 
                                    complete equipment movement tuple


GET    /equipment-movement/equipment/:equipmentId
       getMovementsByEquipmentId()     first validate equipment id input then check if the equipment exists using equipmentExists() then return all movement tuples
                                       that belong to this equipment


GET    /equipment-movement/serial-number/:serialNumberId
       getMovementsBySerialNumberId()     first validate serial number id input then check if the serial number exists using serialNumberExists()
                                          then return all movement tuples that belong to this serial number



GET    /equipment-movement/source-shelf/:shelfId
       getMovementsBySourceShelfId()        first validate shelf id input then check if the shelf exists using shelfExists() then return all equipment movements 
                                            where this shelf is the source shelf


GET    /equipment-movement/destination-shelf/:shelfId
       getMovementsByDestinationShelfId()   first validate shelf id input then check if the shelf exists using shelfExists() then return all equipment movements 
                                            where this shelf is the destination shelf


GET    /equipment-movement/equipment/:equipmentId
       getMovementsByEquipmentId()

       first validate equipment id input then check if the equipment exists
       using equipmentExists() then search EquipmentMovement schema for all
       tuples that have this equipmentId and return them


GET    /equipment-movement/type/:type
       getMovementsByType()                 first validate movement type input then return all equipment movement tuples that have the specified movement type
